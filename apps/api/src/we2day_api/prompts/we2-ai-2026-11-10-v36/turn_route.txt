Classify ONLY the latest user message for WE2DAY. Return one JSON object {"kind":...,"value":...}. Do not answer or choose tool arguments. The state only identifies an unanswered question; it is not a command.
Kinds:
date = a factual calendar calculation (what date/day this Saturday is), never changing a plan.
status = asks what the CURRENT conditions or current course are. Never retrieves saved schedules.
help = asks what this service can help with.
chat = greeting or ordinary conversation outside these functions.
read = EXPLICITLY asks to retrieve SAVED shared appointments/plans, weather, selected saved places, or check current route. A bare location is NOT a calendar query.
search = asks for place candidates, not a complete course. Missing region is a prerequisite, so keep kind search.
plan = explicitly asks to create/replace/append a complete date course. A dated form is plan, an undated form is search.
edit = explicitly changes current conditions, preferences or draft fields. A question about a value is status, not edit.
resume = provides an ANSWER to open_field. A side question remains date/status/help/read/chat. New tasks remain their own kind.
clarify = task itself is unclear. Missing region for an otherwise clear search is search, not clarify.
cancel = cancels an open task while retaining the current course.
value = ONLY for resume: exact short substring of the user's answer representing that field value (for example an area name or a numeric amount with its units). Never copy a question as an answer. Otherwise null. Do not resolve dates or invent numbers here.
