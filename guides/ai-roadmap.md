# 위투 AI

[README](../README.md) · [현재 아키텍처](architecture.md)

## 서비스 안에서 코스 작성

데이트 플랜 목록의 **위투 AI**를 엽니다. 날짜·지역·원하는 활동을 입력하면 한국어로 대화하며 코스를 제안합니다. **초안 저장**을 누르면 기존 플랜 목록에 저장됩니다. 저장한 초안을 열어 장소를 검색하고, 내용을 확인한 후 별도로 확정하면 달력에 반영됩니다.

대화는 작성자 전용 기록으로 저장됩니다. 코스를 달력에 반영하려면 초안 저장과 확정을 별도로 진행하세요. AI는 기존 일정이나 계정·사진·개인 일정을 자동 조회하지 않습니다. 전송 버튼을 누르면 최근 대화와 현재 제안만 Cloudflare로 전송합니다. 별도 동의 체크박스는 없으며 입력창 아래 전송 안내를 제공합니다. 실제 장소·주소·영업정보는 편집 화면에서 직접 확인하세요. AI가 자동 저장·확정하거나 기존 일정을 변경하지 않습니다.

## 서버 설정

Supabase에 마이그레이션을 순서대로 적용합니다. 내부 AI의 기본 카운터는 SQL036, 제공량 기준과 연속 호출 제한은 SQL038에서 적용됩니다. API 서버의 비밀 환경 파일에 다음 두 항목을 설정하고 API를 재시작합니다. 브라우저 공개 환경변수로 넣지 않습니다.

```dotenv
WE2DAY_CLOUDFLARE_ACCOUNT_ID=
WE2DAY_CLOUDFLARE_API_TOKEN=
```

Cloudflare Workers AI → Use REST API에서 현재 계정에만 Workers AI Read/Edit 권한을 가진 전용 토큰을 발급합니다. 고정 모델은 `@cf/qwen/qwen3-30b-a3b-fp8`입니다. 기존 FastAPI가 REST API로 호출하므로 별도 Worker·D1·R2나 서비스 이전은 필요 없습니다.

Workers Free는 제공량 소진 시 중단합니다. Workers Paid 사용 시 제공량 초과분이 청구될 수 있으므로 계정의 플랜 상태를 직접 확인하세요. 앱 자체의 하루 50회 제한은 없습니다. Cloudflare Workers Free의 계정별 일일 제공량을 기준으로 중단하며, 대화 길이와 출력량에 따라 가능한 요청 횟수가 달라집니다. 무료 제공량은 UTC 0시(한국 오전 9시)에 초기화됩니다. 연속 요청 방지를 위한 프로젝트 공통 5초 간격은 서버 재시작 후에도 유지됩니다. 입력은 시스템 지침 포함 16KB, 출력은 최대 2,048토큰입니다. 다른 앱의 Cloudflare 사용량까지 통제하지는 않습니다. 공급자 한도·오류 때 자동 재시도나 다른 유료 모델로 전환하지 않습니다.

## 구성과 한계

브라우저 → 같은 출처의 인증 중계 → FastAPI → DB 사용량 예약 → Workers AI 순서입니다. 답변의 JSON·플랜 형식을 검증한 뒤 화면에 표시합니다. 일반 서버 로그에는 대화·키 원문을 기록하지 않습니다. 작성자 전용 DB에는 성공한 질문·답변·제안과 지침 버전을 보관하고, 별도로 날짜별 호출 횟수를 기록합니다. 초안 저장은 기존 사용자 권한과 요청 재시도 계약을 사용합니다.

대화 횟수로 세션을 차단하지 않습니다. 최근 최대 11개 메시지와 현재 코스를 입력 상한 안에서 전달하며, 오래된 대화는 화면에 남아 있어도 모델 입력에서 제외될 수 있습니다. 완성된 답변을 검증 후 표시합니다. 토큰 스트리밍·장기 대화 요약·기존 플랜 자동 편집은 제공하지 않습니다. 향후 필요성과 데이터 정책을 정한 뒤 검토할 확장입니다.

외부 ChatGPT의 [일정·코스 관리 연결](agent-api.md)은 별도 기능입니다. 외부 연결 키나 OAuth 토큰을 내부 AI에 전달하지 않습니다.

공식 참고: [REST 설정](https://developers.cloudflare.com/workers-ai/get-started/rest-api/), [모델](https://developers.cloudflare.com/workers-ai/models/qwen3-30b-a3b-fp8/), [무료 한도](https://developers.cloudflare.com/workers-ai/platform/pricing/).

일일 무료 제공량 소진 오류(3036)와 일시적인 처리 용량 부족(3040)을 구분해 안내합니다. 앱의 호출 횟수 카운터는 Cloudflare의 정확한 Neuron 사용량이나 남은 무료량을 뜻하지 않습니다.

### 내 대화

위투 AI 상단의 대화 기록 아이콘에서 본인이 작성한 대화를 열어 이어갈 수 있습니다. 새 대화는 기존 기록을 삭제하지 않습니다. 성공한 질문·답변·코스 제안과 지침 버전을 저장하며 다른 계정과 외부 일정 도우미에는 공개하지 않습니다. 최근 100개 대화와 대화별 최근 50개 응답을 먼저 불러오며, 이전 대화 버튼으로 앞부분을 조회합니다. 새로고침하면 최근 대화를 복원합니다. 실패한 요청은 성공 기록에 추가하지 않습니다. 도입 전에 저장되지 않은 대화는 복구되지 않습니다.
